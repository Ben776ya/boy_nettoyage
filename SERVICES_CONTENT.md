## Service Page Layout & Structure

Every service has its own dedicated page at `/services/[slug]`. Here is the exact structure of that page, section by section.

---

### Page Structure Overview

```
Header (navbar)
│
├── 1. HERO SECTION  (full-width gradient banner)
│
├── 2. MAIN CONTENT  (2-column grid)
│   ├── LEFT COLUMN (2/3 width)
│   │   ├── Prestations
│   │   ├── Target Clients
│   │   ├── Coverage Area
│   │   ├── Why Choose Us
│   │   └── FAQ Accordion
│   │
│   └── RIGHT COLUMN — SIDEBAR (1/3 width)
│       ├── Mobile CTA card  (only on mobile)
│       ├── OTHER SERVICES panel  ← the navigation list
│       └── Desktop sticky CTA card  (only on desktop)
│
├── 3. BOTTOM CTA SECTION
│
Footer
WhatsApp floating button
Scroll-to-Top button
```

---

### 1. Hero Section

Full-width gradient banner (dark green → primary green). Contains:

- **Breadcrumb:** `Home > Services > [Service Name]`
- **Badge pill:** service icon + label "Service Professionnel"
- **H1 title:** the service name
- **Intro paragraph:** the intro text (see each service above)
- **Two CTA buttons:**
  - "Demander un Devis" → links to `/#contact`
  - Phone number button → `tel:` link
- **Service image** (right side on desktop, stacked below text on mobile) — 16/10 aspect ratio, rounded corners, drop shadow

Layout: text on the left, image on the right (flex row on `lg`, stacked on mobile).

---

### 2. Main Content — Left Column

A `2/3` width column containing 5 stacked sections, each with a heading that has a small icon in a rounded square.

#### 2a. Prestations ("Nos Prestations")
- Heading with a `CheckCircle` icon
- Content: **2-column grid of cards** (1 column on mobile)
- Each card has: gradient checkmark circle + prestation text
- Animate in on scroll with staggered delay

#### 2b. Target Clients ("À qui s'adresse ce service ?")
- Heading with a `Users` icon
- Content: single paragraph in a white bordered card

#### 2c. Coverage Area ("Zone d'intervention")
- Heading with a `MapPin` icon
- Content: single paragraph in a white bordered card

#### 2d. Why Choose Us ("Pourquoi nous choisir ?")
- Heading with a `Star` icon
- Content: **vertical list of cards**, each with a small colored dot bullet + text
- Animate in on scroll from left with staggered delay

#### 2e. FAQ ("Questions fréquentes")
- Heading only (no icon)
- Content: **accordion component** — click a question to expand/collapse its answer
- One question open at a time; chevron rotates 180° when open

---

### 2. Main Content — Right Column (Sidebar)

The sidebar has 3 blocks stacked vertically:

#### Block A — Mobile CTA (hidden on desktop `lg:hidden`)
A green gradient card showing:
- Short title + short body text
- "Devis Gratuit" button (white bg, green text) → `/#contact`
- "Appeler" button (transparent with white border) → `tel:` link

#### Block B — Other Services Panel ← THE NAVIGATION LIST

This is the panel that lets users navigate between all services from inside a service page.

- **Title:** "Nos autres services"
- A **scrollable vertical list** of all other services (every service except the current one)
- Each row contains:
  - Small icon in a rounded square (green tint background, green icon)
  - Service name as text
  - The whole row is a clickable link to `/services/[slug]`
  - On hover: light green background tint + text turns primary green
- All 23 remaining services are listed (the current service is excluded)

```
┌─────────────────────────────────────────┐

├─────────────────────────────────────────┤
```
